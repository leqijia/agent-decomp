
# Oracle State Generation Pipeline

This module generates oracle states for agent trajectories on WebArena tasks.
Oracle states are structured representations of task state at step t, used in 
Experiments 1, 2, and 3. See proposal Section 2.1 for formal definitions.

---

## What is an oracle state?

An oracle state St at step t is defined as:

    St = (g, P_t, R_t, e_t, C, F_t, K_t)

where:
- g:   task goal
- P_t: completed subtasks at step t
- R_t: remaining subtasks at step t
- e_t: ground-truth environment state (from DOM, not agent observation)
- C:   active constraints
- F_t: failed attempts with correctly attributed causes
- K_t: key facts extracted from trajectory

Oracle states are generated by Claude Sonnet with access to the ground-truth 
DOM queried directly from the WebArena Docker environment — access the task 
agent does not have.

## Setup

### 1. Install dependencies
pip install -r requirements.txt

### 2. Set up environment variables
cp .env.example .env

Open .env and add:
OPENROUTER_API_KEY=your_key_here

Never commit .env. It is already in .gitignore.

### 3. Verify your environment
python generate_oracle.py --test

This runs without hitting the API and prints a fake oracle state to confirm 
everything is wired up correctly.

---

## Usage

### Generate a single oracle state
python generate_oracle.py \
  --trajectory trajectories/shopping_003.json \
  --step 12 \
  --prompt_version v2 \
  --output_dir outputs/

### Validate outputs
python validate_oracle.py --input_dir outputs/

Prints a report of which files have missing or empty fields.

---

## Prompt versioning

Always specify --prompt_version when running scripts. Never overwrite an 
existing version file — create a new one (v3, v4 etc.) so outputs remain 
reproducible.

Current versions:
- v1: baseline prompt, free text output
- v2: added DOM grounding rules, empty field handling, step anchor, 
      oracle access framing

See quality_notes.md for field-level accuracy notes across versions.
